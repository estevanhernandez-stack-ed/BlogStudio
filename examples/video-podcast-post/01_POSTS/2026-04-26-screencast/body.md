# Building a Plugin Live

This 22-minute screencast walks through building a Claude Code plugin from scratch — from `mkdir` to a working `/hello` slash command. If you've been meaning to write your first plugin and just need to see the shape of the code, this is the one to watch.

## What you'll see

- The minimum plugin manifest
- One slash command, one skill, no scaffolding tools
- The `~/.claude/plugins/` install path
- Testing the plugin without publishing

## Why screencasts for this

Plugin authoring has a high "what does the directory look like" overhead. A 22-minute video shows it; 3000 words of prose can describe it. Both have their place — the video for the *shape*, the prose (this post + the transcript below) for the *details*.
