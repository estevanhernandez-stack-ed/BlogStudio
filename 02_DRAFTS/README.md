# 02_DRAFTS

In-progress posts that aren't ready to be built yet.

## What lives here

Half-formed ideas, posts you're drafting but don't want appearing in `dist/` outputs. The build pipeline ignores everything in this directory.

## Promotion to live

When a draft is ready, move the entire post directory from `02_DRAFTS/` to `01_POSTS/`. The build picks it up on the next run.

## Distinction from `body.md` work-in-progress

A draft post here might not even have its per-target frontmatter files yet — just `body.md` with notes. That's fine. Drafts can be unstructured.
